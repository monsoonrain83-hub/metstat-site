## ۲. تفاوت‌های بنیادین طراحی و هویت بصری

### ۲.۱ پالت رنگی و تم

**R5 (مرجع شما):**
```css
:root {
  --sky: #399FD4;
  --paper: #F8F9FD;
  --scarlet: #DC1937;
  --ink: #183b53;
  --muted: #577489;
  --bg: #eaf4fa;
  --line: #c2dfed;
  --status-good: #17b486;
  --status-bad: #eb5569;
  ...
}
```
- تم **روشن** (Paper / Sky)
- هدر گرادیان آبی Sky → سفید
- دکمه‌های فعال: پس‌زمینه Scarlet + متن سفید
- سایه و «فشردن دکمه» (translateY + box-shadow) مشخص

**ChatGPT:**
- تم غالب **تیره** (`--ink:#e6ecf5`, `--paper:#0f1726`, `--card:#172236`, accent آبی `#2563eb` / `#4b9bff`)
- رنگ Scarlet رسمی R5 تقریباً غایب است؛ به‌جای آن قرمزهای Tailwind-مانند (`#dc2626`, `#b91c1c`)
- هیچ تطبیق دقیقی با `--sky / --paper / --scarlet` دیده نمی‌شود

**خطای ChatGPT:** هویت رنگی R5 (Sky + Scarlet + Paper) کاملاً نادیده گرفته شده.

### ۲.۲ معماری DOM و کلاس‌ها

| عنصر | R5 | ChatGPT |
|------|----|---------|
| ریشه | `.app` + `data-mode` | `.top` + اسکریپت‌های ms9/ms8 |
| هدر | `.header` (۶۴px ثابت، برند M، nav-group، header-tools) | `.top` / `.menuBar` / `.top-in` |
| نوار عنوان | `.title-strip` + breadcrumb + non-live | ساختار متفاوت |
| نوار جغرافیا | `.geo-bar` (grid ۵ ستونه + قاره/منطقه/کشور/استان/شهرستان) | وجود دارد اما استایل و جزئیات متفاوت |
| فضای کار | `.workspace` → sidebar + content | چیدمان متفاوت |
| سایدبار | `.sidebar` با CONTROL CENTER، tab-switch، custom-shortcut | کارت‌ها و کنترل‌های NWP جابه‌جا/بازتولیدشده |
| نقشه | `.map-card` + `.map-stage` + view-layer | متفاوت |

ChatGPT از کلاس‌ها و اسکلت R5 پیروی نکرده؛ ساختار ریشه‌ای دیگری (r8/r9) را نگه داشته.

### ۲.۳ هدر و ابزارهای بالا

**R5 مشخصات اجباری:**
- برند: `brand-mark` با حرف **M** داخل مربع سفید + متن MetStat / METEOROLOGICAL ATLAS
- `preview-state`: «● پیش‌نمایش r5»
- دکمه صدا: `#soundBtn` با علامت **♪**
- دکمه‌های اندازه فونت: `A−` / `A+`
- منوی حساب کاربری (guest / user-demo / admin-demo) با dropdown

**در خروجی ChatGPT:**
- لوگوی base64 بزرگ و متفاوت
- دکمه **♪** و سیستم صدای کلیک طبق R5 دیده نمی‌شود (یا اگر هست، در همان جای هدر R5 و با همان رفتار نیست)
- `preview-state` با متن «پیش‌نمایش r5» وجود ندارد
- منوی حساب و نقش‌های نمایشی (guest/user/admin) به شکل R5 پیاده نشده

**خطای ChatGPT:** هدر R5 بازسازی نشده؛ فقط «هدر فشرده» از نسخهٔ دیگری آمده.

## ۳. مشکلات مشخصی که شما اشاره کردید (تأیید + جزئیات)

### ۳.۱ Colorbar و منوی کشویی

- در R5، colorbar / legend بخشی از جریان UI نقشه و کنترل‌های جانبی است و انتظار می‌رود با منوی کشویی / انتخاب پارامتر هماهنگ باشد.
- در ChatGPT تعداد زیادی ارجاع به `colorbar` در متن کمک و منطق نقشه وجود دارد، اما **ظاهر و رفتار کشویی مطابق R5** (مثلاً parameter-menu با details/summary و دکمهٔ انتخاب) رعایت نشده.
- نتیجه: colorbar از نظر کاربر «غریبه» و غیر R5 به نظر می‌رسد.

**نیاز اصلاح:** colorbar و انتخاب پارامتر باید دقیقاً از الگوی `.parameter-selector` / `.parameter-menu` / `.parameter-trigger` R5 پیروی کند.

### ۳.۲ افکت صوتی (کلیک)

- R5: دکمه `#soundBtn` در `header-tools` + منطق روشن/خاموش کردن صدای کلیک.
- ChatGPT: سیستم صوتی یکپارچه با همان دکمه و رفتار در هدر R5 **وجود ندارد** (یا در جای دیگر و با UX متفاوت است).

**نیاز اصلاح:** بازگرداندن دکمه ♪، وضعیت `aria-pressed`، و صدای کلیک دقیقاً مثل R5.

### ۳.۳ آیکون‌ها

- R5: مجموعهٔ SVG داخلی (sprite) با `use href="#i-..."` (نقشه، multi، info و …)، اندازه و stroke یکدست (حدود ۱۹px، stroke-width 1.9).
- ChatGPT: آیکون‌ها یا از مسیر دیگر می‌آیند یا استایل/جای متفاوت دارند؛ با سیستم sprite و ظاهر R5 هم‌خوان نیست.

**نیاز اصلاح:** استفاده از همان sprite و قوانین اندازه/رنگ R5؛ جابه‌جایی آیکون‌ها در هدر، سایدبار و geo-bar باید مطابق مرجع باشد.

### ۳.۴ بیرون‌زدگی و overflow

- R5 صریحاً برای desktop-geometry در همهٔ اندازه‌ها طراحی شده (`min-width:960px`، pinch-zoom، overscroll کنترل‌شده).
- ChatGPT اسکریپت‌های viewport و fit موبایل (ms9-touch-desktop-viewport و …) دارد که با هندسهٔ ثابت R5 تداخل ایجاد می‌کند و می‌تواند باعث بیرون‌زدگی یا مقیاس نامناسب شود.

**نیاز اصلاح:** حذف/غیرفعال‌سازی لایه‌های viewport ناسازگار و پایبندی به `min-width` و قوانین overflow R5.

### ۳.۵ جزئیات منوها

- منوهای کشویی R5 (`.nav-menu`) با فاصله، سایه، رنگ Scarlet روی hover/current، و `aria-current` مشخص‌اند.
- در ChatGPT منوبار (`menuBar`) از خانوادهٔ دیگری است؛ جزئیات hover، فاصله، و سلسله‌مراتب صفحه با R5 یکی نیست.

## ۴. مقایسهٔ بخش‌به‌بخش (چک‌لیست اصلاح برای ChatGPT)

### ۴.۱ باید دقیقاً مثل R5 باشد (اولویت بالا)

1. **`:root` و پالت** — Sky / Paper / Scarlet / Ink / Muted / Line و status colors.
2. **ساختار `.app` > `.header` > `.title-strip` > `.geo-bar` > `.workspace`**.
3. **هدر:** brand-mark «M»، preview-state «● پیش‌نمایش r5»، soundBtn ♪، A−/A+، account dropdown با سه حالت نمایشی.
4. **دکمه‌ها:** کلاس‌های `.nav-button`, `.control`, `.tab-switch`, `.chip-option`, `.sidebar-button` با حالت active Scarlet و افکت فشردن.
5. **سایدبار:** CONTROL CENTER، tab مدل‌ها / مولتی‌مدل سفارشی، custom-shortcut با ＋.
6. **parameter-menu** با details/summary و دکمه‌های پارامتر.
7. **geo-bar** پنج‌گانه با همان لیبل‌ها و grid.
8. **سیستم صدا** و دکمهٔ آن در هدر.
9. **آیکون‌های SVG** از sprite داخلی R5.
10. **حالت‌های data-mode** (forecast / custom / home / tool / account) و view-layerها.

### ۴.۲ چیزهایی که در ChatGPT «هستند» ولی R5 نیستند / یا اشتباه پیاده شده‌اند

- تم تیره و رنگ‌های Tailwind-مانند
- عنوان و build tag r8.1 / r9.6 به‌جای «نسخه جامع r5»
- اسکریپت‌های fit موبایل و lazy-load دارایی‌های سنگین که در R5 تک‌فایل و بدون وابستگی خارجی تعریف شده
- منطق colorbar در لایهٔ داده/کمک، بدون UI کشویی مطابق R5
- عدم وجود یا جابه‌جایی افکت صوتی کلیک
- تفاوت در جای آیکون‌ها و اندازهٔ کنترل‌ها

### ۴.۳ چیزهایی که در R5 هست و در خروجی ChatGPT ناقص یا غایب است

- پیش‌نمایش نقش‌های حساب (guest / user-demo / admin-demo) بدون اتصال واقعی
- Drawing tools تاریخی (P18) با pan/ruler/جبهه/H-L و …
- Ava Studio و LightningLabWebCore به‌صورت preview محلی
- watermark و placeholder نقشه با متن DEMO
- notice و warning با لحن «بدون داده زنده»
- فونت و اندازهٔ دقیق پنل (`--panel-font: 14px` و قوانین related)

## ۵. دستورالعمل اصلاح برای ChatGPT (قابل کپی)

لطفاً خروجی فعلی را **بازنویسی** کنید تا با فایل مرجع `OPEN_METSTAT_R5_ANDROID_FIXED` هم‌راستا شود. قواعد الزامی:

1. **فقط** از پالت و کلاس‌های CSS همان فایل R5 استفاده کنید؛ تم تیره و متغیرهای r8/r9 را حذف کنید.
2. اسکلت HTML باید همان باشد:  
   `div.app[data-mode]` → `header.header` → `div.title-strip` → `section.geo-bar` → `main.workspace` (sidebar + map-card).
3. هدر باید شامل: brand-mark M، preview-state، soundBtn ♪، A−/A+، و منوی حساب با سه حالت نمایشی باشد.
4. colorbar / انتخاب پارامتر باید از الگوی `.parameter-selector` + `.parameter-menu` R5 پیروی کند (منوی کشویی، نه فقط متن help).
5. افکت صوتی کلیک را با دکمهٔ ♪ در همان جای هدر پیاده کنید.
6. آیکون‌ها را از sprite داخلی R5 بگیرید؛ اندازه و stroke را تغییر ندهید.
7. هیچ viewport-fit یا zoom موبایل ناسازگار با `min-width:960px` و هندسهٔ دسکتاپ R5 اضافه نکنید.
8. عنوان صفحه و badge باید «MetStat Atlas — نسخه جامع r5» / «پیش‌نمایش r5» باشد، نه r8.1 یا r9.6.
9. بیرون‌زدگی، فاصلهٔ منوها، و حالت active دکمه‌ها را پیکسل‌به‌پیکسل با R5 تطبیق دهید.
10. قابلیت‌های نمایشی (حساب، drawing، studio) را فقط در حد UX پیش‌نمایش R5 نگه دارید؛ دادهٔ زنده اضافه نکنید.

پس از اصلاح، یک چک‌لیست کوتاه بدهید که موارد ۱–۱۰ بالا را یکی‌یکی تأیید کرده باشد.
