## Independent rainfall catalog
Build a new catalog outside the public document root, independent of Atlas. Import all sources read-only: existing private V45-compatible catalog (check installed revision), Atlas official and review registries, complementary stations, synoptic, climatological, rain gauge, automatic, hydrometric, user-supplied station/OSM engine and city/village gazetteers. Preserve all original source IDs, original names, coordinates, provenance and licenses; never merge records by name or proximity alone. Keep geographical reference points separate from measuring sites; hydrometric sites only eligible for observed rainfall if actual precipitation instrument identity is established. Preserve current encrypted DB/key, do not publish raw private data or credentials.
Catalog needs stable ID, Persian name, verified or explicitly generated Latin spelling, aliases, WGS84 lat/lon, elevation m and elevation source (station/DEM/unknown), province and county IDs/names, network/type, observed parameters, coordinate quality, source and evidence, review state. Fill administrative regions by authoritative polygon spatial join, flag boundary conflicts; DEM-derived elevation must be labeled, not replace measured elevation. Keep missing values null. OSM centroid is not sensor coordinates. Deduplicate only with documented identity links; do not remove original records.
## Resolver pipeline
Use legacy exact/alias/learned verified matches plus normalized Persian/Latin, province/county, new catalog multi-source candidates, controlled fuzzy/phonetic search, and final AI assistance only for unresolved/ambiguous rows. AI receives minimum candidate/evidence context server-side, returns candidate IDs with evidence or abstains; no invented coordinates or auto-confirmation solely on model confidence. External calls optional/configurable, rate limited, cached, with timeouts and no exposed keys. A failed AI call must not block existing confirmed records. Verified human choices may become scoped aliases after audit, never a globally ambiguous alias.
