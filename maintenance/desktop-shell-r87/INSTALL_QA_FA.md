# MetStat r87 — پیش‌نویس چیدمان ثابت دسکتاپ + تکمیل لایهٔ شهر و روستا

## وضعیت و محدودیت حیاتی
- **طرح Figma خوانده نشد.** اتصال Figma به فایل `h9lb9hKlGLTJ5yeqXtUnix` خطای «no edit access» می‌دهد. رنگ‌های آبی/سرمه‌ای r87 صرفاً **تم آزمایشی منظم** است، **کپی تأییدشدهٔ قالب Figma نیست**.
- کد بر مبنای `MetStat r86` ساخته شده، **نه آخرین محتوای زندهٔ cPanel**. بدون تطبیق SHA256، فایل‌های موجود را کورکورانه جایگزین نکنید. شاخهٔ GitHub نیز Draft است.
- تمامی روال‌های محاسباتی و فرمول‌ها، همهٔ شناسه‌های DOM و تعداد کنترل‌های `<select>` فایل index اصلی حفظ شده‌اند؛ این آزمون ایستا، ادعای آزمون کامل احراز هویت/مدل‌های زنده نیست.

## منبع داده و تعدادها
- مبنا: فایل Excel ارسالی کاربر (`iran_osm_nodes_database.xlsx`)، تبدیل‌شده از OSM PBF ایران به بانک `r86` و shardهای استخراج‌شدهٔ بدون تغییر شناسهٔ OSM.
- OSM nodeهای نقطه‌ای نام‌دار در بانک مادر: ۵۸٬۶۸۲ مورد؛ از این‌ها ۵۵٬۰۶۵ نقطهٔ مسکونی/کشاورزی برای این **لایهٔ جدید** انتخاب شدند: روستا ۳۹٬۸۱۲، آبادی کوچک و نقاط محلی ۶٬۴۸۶، محله ۶٬۰۸۲، شهرک ۱٬۴۷۳، حومه ۱٬۰۳۵، شهر ۸۷، مزرعه/باغ ۹۰.
- فایل خروجی `data/osm_settlements_v87.json` عمومی و مشتق از OSM تحت ODbL است. هنگام انتشار باید عبارت © OpenStreetMap contributors در سایت به شکل قابل مشاهده درج شود. این داده‌ها **ایستگاه هواشناسی نیستند**.
- پایگاه اصلی ۷٬۰۴۹ ایستگاه و کلید رمزگذاری اصلاً دست‌کاری نشده است. بانک خصوصی OSM نسخهٔ ۸۶ و قله‌های آن هم تغییر نکردند.

## رفتار جدید نقشه‌ها
- روی نقشه‌های NWP و ماهواره‌ای: در مقیاس منطقه‌ای/خاورمیانه **پایتخت‌ها**؛ روی ایران **مراکز استان**؛ در مقیاس استان **مراکز شهرستان**؛ در مقیاس شهرستان **سایر نقاط شهری/روستایی/کشاورزی** پس از اولویت مراکز اداری.
- آستانه بر اساس *عرض جغرافیایی نمای فعلی* است: منطقه >۳۳ درجهٔ طول، کشور ۱۵–۳۳، استان ۲٫۶–۱۵، شهرستان ≤۲٫۶. این آستانه یک تنظیم قابل آزمایش برای نقشه‌نگاری است؛ محدوده‌های اداری واقعی نامنظم‌اند.
- نماد روستا از مثلث قهوه‌ای به **دایرهٔ فیروزه‌ای** تغییر کرده، نماد شهر همچنان مستقل است و قله‌ها از تغییر مستثنا هستند؛ مزارع نماد **چهارگوش توخالی سبز** دارند.
- نقاط OSM مکمل داده‌های GeoNames/SEATS فعلی‌اند: نقاط هم‌نام نزدیک به مراکز قدیمی نمایش مضاعف نمی‌گیرند، اما دادهٔ قبلی حذف/جابه‌جا نمی‌شود.
- در شهرستان نقاط بیشتر رسم می‌شوند، اما برچسب‌ها به ترتیب طبقه و بدون روی‌هم‌افتادگی شدید و با سقف وابسته به فضای نمایش انتخاب می‌شوند. تیک «شهرها» و «روستاها» مستقل‌اند.
- لایهٔ جدید بعد از رسیدن به زوم شهرستانی **به‌طور تنبل (lazy)** واکشی می‌شود تا صفحهٔ اصلی بی‌دلیل ۵٫۲ مگابایت اضافه نگیرد. درخواست بدون داده/بدون اینترنت فقط هشدار Console می‌دهد و لایهٔ قبلی را خراب نمی‌کند.

## نمای ثابت دسکتاپ روی موبایل و PC
- برای موبایل `meta viewport` به **عرض مجازی ۱۳۶۰ پیکسل بدون initial-scale اجباری** تبدیل شد. مرورگر کل صفحهٔ دسکتاپ را در عرض موبایل کوچک می‌کند و برای خواندن جزئیات امکان بزرگ‌نمایی دستی باقی است. **هیچ طرحِ تک‌ستونه/زیرهم برای موبایل تولید نشده**.
- ستون باریک نخست = منوی اصلی سایت در راست (در فارسی)، ستون باریک دوم = تنظیمات/ابزار همان صفحه؛ نقشه/نمودار/جدول سمت چپ و پهن. در انگلیسی این ترتیب قرینه می‌شود.
- منوی اصلی از DOM اصلی کپی یا حذف نشده؛ تنها CSS آن به ستون ثابت تبدیل شده است تا event handlerهای موجود باقی بمانند. تعریف رنگ‌ها در `assets/metstat_desktop_shell_v87.css` جمع شده، و رنگ‌نقشه‌ها/پالت‌های علمی دست نخورده‌اند.
- صفحهٔ اطلس با دو ستون باریک تنظیمات داخلی همچنان در کنار کادر اصلی قرار می‌گیرد؛ سایر صفحات همان ساختار داخلی‌شان را نگه می‌دارند.

## آزمون‌ها
1. تمامی شناسه‌های DOM و تعداد فهرست‌های `<select>` در index، عیناً مانند r86 حفظ شدند؛ هیچ صفحهٔ ناوبری از فایل اصلی حذف نشده.
2. `node --check`: همهٔ اسکریپت‌های inline index و هفت اسکریپت هم‌بارش پس از اصلاح syntax سالم‌اند؛ CSS جدید و موجود با `tinycss2` بدون خطای نحوی پردازش شد.
3. آزمون Chromium به روش `page.set_content` (بدون asset و احراز هویت) روی دسکتاپ ۱۴۴۰ و موبایل فیزیکی ۳۹۰: viewport مجازی موبایل ۱۳۶۰؛ نوار سراسری در راست، تنظیمات داخل ستون راست و نقشه سمت چپ؛ هیچ بیرون‌زدگی ریشه در مورد آزمایشی ثبت نشد. CSS layout روی DOM واقعی و با دادهٔ ساختگی برای کنترل‌ها بررسی شد. 
4. آزمون مرورگر مستقل لایهٔ OSM: کل ۵۵٬۰۶۵ رکورد نمایه‌سازی شد و برای نمای شهرستانی بیش از ۱٬۰۰۰ نقطهٔ واقعی بازیابی و به Canvas سپرده شد.
5. **مرورگر سایت کامل** به دلیل `I18N_D is not defined` در اجرای بدون assetهای اصلی و `ERR_BLOCKED_BY_ADMINISTRATOR` برای localhost آزمون end-to-end نداشت؛ این خطا ناشی از ناقص بودن محیط آزمون است، نه اثبات سالم یا خراب بودن سایت زنده.
6. Figma با خطای edit permission پاسخ می‌دهد؛ طراحی pixel-perfect هنوز شروع نشده.

**نتیجه:** مرحله r87 یک **پیش‌نویس نصب مشروط/آزمایشی** است؛ جایگزین تاییدشدهٔ طراحی Figma یا آزمون کامل سایت نیست.
