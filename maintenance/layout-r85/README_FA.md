# MetStat — وصلهٔ ساختار index و منوها (r85)

نسخهٔ مبنا: SHA256 `b5005c16ebaba3994d98f7ffe151115e38e46e5ce0d775c7ece08b140397bd80`

خروجی وصله: SHA256 `de87808fb73fe73373d9070c06169537eb5522223306c815bd71f57115cf507d`

## هدف

- رفع تحمیل viewport و min-width برابر ۱۲۲۰ پیکسل روی موبایل
- جلوگیری از مخفی‌شدن دکمه‌های نوار ناوبری (پیمایش افقی واقعی)
- یکپارچه‌سازی محل منوهای کشویی و رویدادهای mirrored selects
- رفع مشکل پنل‌های بازشونده داخل ستون اسکرول‌دار
- حفظ اطلاعات مدل GEM و مسیرهای فعلی NWP بدون دخالت در منطق داده

## بازتولید و آزمون

پچ فقط روی فایل اصلی با SHA مبنا اجرا می‌شود و منبع را overwrite نمی‌کند:

```bash
python patch_index.py --input /path/to/current/index.html --output /tmp/index_r85.html
python verify_r85.py /tmp/index_r85.html
```

توجه: آزمون مرورگر با stub صرفاً برای فایل‌های assets که در HTML ضمیمه نشده‌اند انجام می‌شود؛ این stubها در نسخهٔ نصب وجود ندارند. تست production واقعی باید روی هاست با همهٔ assetها، Auth و مانیفست‌های اصلی انجام شود.

## نصب

۱. بکاپ فایل `public_html/index.html` بگیرید.
۲. SHA فایل روی هاست را با SHA مبنا مقایسه کنید. اگر متفاوت است، **overwrite نکنید**؛ تغییرات را merge کنید.
۳. خروجی patch را پس از آزمون در `public_html/index.html` جایگزین کنید.
۴. منوها، GEM، پنل لایه‌ها، حالت تمام‌صفحه، موبایل و دسکتاپ را روی هاست آزمایش کنید.
