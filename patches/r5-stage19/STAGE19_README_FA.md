## اصلاح جدید واقعی

- بازسازیِ دوبارهٔ کنترل‌های Stage18 انجام نشده. در Stage18 خود کالربار (`nvLg`) از قبل به منوی اصلی پالت متصل است؛ افزونه **این handler را تشخیص می‌دهد و دوباره اضافه نمی‌کند**. برای نسخه‌های فاقد آن، پشتیبان کلیک و کلیدهای Enter/Space به منوی اصلی وصل می‌شود.
- آیکون لایه‌ها، در صورت وجود SVG بومی Stage18، دست‌نخورده باقی می‌ماند؛ در نسخه‌های قبلی با سه لایه واقعی SVG به همان `summary` اضافه می‌شود، بدون افزودن دکمه یا پنل تکراری.
- ترجمهٔ مشخص و قابل برگشت هفت عنوان منوی اصلی (بدون تغییر آیکون، پیکان و رویداد ناوبری)، پنج انتخابگر قاره/منطقه/کشور/استان/شهرستان و گزینه‌های شناخته‌شده آن‌ها، گزینه‌های مرز، برچسب لایه‌ها و بخشی از ابزارهای واقعی نقشه در نسخه انگلیسی و فارسی؛ `value`، رویدادها، مدل‌ها، پارامترها، داده‌های هواشناسی و مسیرها تغییر نمی‌کنند.

## روش استفاده و بازگشت

`MetStat_R96_R5_STAGE19_ACTUAL_STAGE18_BASE_TEST.zip` شامل `index.html` کامل منطبق با Stage18 و `assets/metstat_map_ui_r201.js` و دو asset جدید است. **برای نصب مستقیم روی هاست فعال نیست:** ابتدا باید `index` و `assets` واقعاً فعال cPanel با آن تطبیق داده شوند و بکاپ خارجی تهیه شود. فایل‌های دیگری که قبلاً روی هاست هستند باید حفظ شوند.

در بسته کوچک `MetStat_STAGE19_R5_PALETTE_LAYERS_DELTA_TEST.zip` می‌توان این فرمان‌ها را فقط در یک پوشه staging استفاده کرد:

```sh
python install_stage19.py /path/to/staging/index.html --dry-run
python install_stage19.py /path/to/staging/index.html
```

نصب‌کننده قبل از نوشتن، وجود شناسه‌های اصلی را بررسی می‌کند، روی دارایی متفاوت بازنویسی انجام نمی‌دهد و `index.html.stage19.bak` می‌سازد. نصب مجدد همان نسخه تغییری ایجاد نمی‌کند. برای rollback فایل پشتیبان را به نام اصلی برگردانید و دو فایل asset جدید را حذف کنید.

- ZIP مرحله ۱۸ واقعاً بازیابی و استخراج شد؛ نه بازسازی از نسخه قدیمی ۱۰:۵۶.
- HTML قبل و بعد ۱۴ اسکریپت inline دارد؛ در هر دو، **۰ خطای syntax** در Node.js.
- ۲۰ محتوای Base64 قدیمی به همان ترتیب و بدون تغییر حفظ شدند.
- ۸ سناریوی مرورگر Chromium روی DOM آزمایشی (۴ اندازه ۳۹۰×۸۴۴، ۸۴۴×۳۹۰، ۹۶۰×۷۲۰، ۱۴۴۰×۹۰۰ × دو زبان) موفق بود؛ شامل کلیک، Enter، Space، عدم تکرار آیکون، بازسازی پنل، حفظ کنترل بومی Stage18 و رفت‌وبرگشت دوزبانهٔ هدر و جغرافیا.
- ۸ آزمون دیگر روی HTML کامل Stage18 در مرورگر آفلاین (`set_content`) موفق بود: هفت منوی هدر، پنج انتخابگر جغرافیا، جابه‌جایی زبان و ثابت‌ماندن `value` و آیکون‌ها. این آزمون، رفتار viewport-fit وابسته به assetهای بیرونی و رندر نقشه واقعی را تأیید نمی‌کند.
- صفحه واقعی نقشه با داده زنده و محیط cPanel هنوز آزمون نشده و ادعای تکمیل همه صفحات یا UI پیکسل‌به‌پیکسل نداریم.
